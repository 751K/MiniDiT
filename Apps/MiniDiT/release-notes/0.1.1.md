修复版本。 / Bug-fix release.

- 中文界面里带数量的文字（如“1 张”“导入 3 个文件”）不再显示成英文。
  Counts in the Chinese interface (such as “1 张” or “导入 3 个文件”) no longer appear in English.
- 英文界面的浏览页标题改为每个词首字母大写，如“12 New Photos”。
  The browse header in English now uses title case, such as “12 New Photos”.

已安装 0.1 的会自动收到更新提示，也可以在「MiniDiT › 检查更新…」中手动检查。
If you have 0.1 installed, MiniDiT will offer this update automatically; you can also choose MiniDiT › Check for Updates….
