# MiniDiT 网页内容依据

内容依据更新于 2026-11-09。定位：便捷导入与专业交接使用同一套项目记录、目录规则和校验流程。

## 页面叙事

1. 导入：两种连接共用导入记录，筛选本次范围，刷新保留选择，中断续传。
2. 项目：普通导入前必须选择或新建项目，同一拍摄任务可以持续接收跨日期、相机和存储卡的多次导入。项目记录归属与文件位置；照片、视频分别设置磁盘和目录规则。直接拖到桌面或访达文件夹可不选择项目。用明确标为示例的路径说明关系。
3. 校验与备份：讲清核对哪些内容、记录什么、怎样复查。副本数量、内容核验和软件接收分开表达。
4. 后期交接：照片进入 C1 会话或 LrC 收藏夹；视频的原片、代理、XML、源时间码、Shot Mark、卷号及色彩处理各自说明用途。

保留原生界面静态图和主交互演示。移除“少一点折腾”“不必是一堆琐事”“三步回到节奏”等未说明产品行为的重复文案。全页白底，不增添装饰动画。

## 主要事实与实现依据

| 页面内容 | 依据 | 表达范围 |
|---|---|---|
| 普通导入必须选项目，直接拖出例外 | AppModel+Import.swift、AppModel+Sessions.swift、AppModel+Background.swift、FileDragSource.swift | 不宣称启动时自动选择最近项目或按日期自动创建；自动导入同样要求已选项目 |
| 跨次归集、项目浏览、移除项目保留文件 | AppModel+Sessions.swift、SessionsView.swift | 项目记录本地文件路径；不承诺自动跟踪外部改名或搬动 |
| 照片视频目录独立、C1 Capture 例外 | ImportOrganization.swift、AppModel+Sessions.swift | 项目管归属；目录规则决定实际写入位置 |
| 内容校验与第二份备份 | FileImporter.swift | 读卡器比对源文件；Wi-Fi 首份检查大小并计算本地哈希，备份读回核对 |
| ASC MHL 文件、大小、时间、校验值 | MHLWriter.swift | 清单可用于兼容工具复查；不宣称已有可读交接报告或应用内独立离线复核 |
| 已导入、已备份角标 | AppModel+Library.swift 的 refreshCopies/copyCount | 当前文件存在与大小检查，不表示刚执行内容复核 |
| 照片交接与机内星级 | CaptureOneBridge.swift、LightroomPlugin.swift、功能清单 | 对应已选择的软件集成，不声称所有照片软件都自动接收 |
| 视频时间码、代理、卷号、Shot Mark 与色彩 | VideoTimecode.swift、FCPXMLWriter.swift、ResolveBridge.swift、功能清单 | 当前支持的片段信息与交接；不宣传计划中的整卡原样拷贝 |
| 兼容性 | README、功能清单 | 当前仅适配 Sony α，α7 V 已实机验证；Apple 芯片、macOS 14+ |

个人/团队是主动应用的推荐配置，全部能力可自行选择。免费开源依据当前 MIT 许可和产品约定，不设置功能分级。

未实现的多个备份目的地、应用内独立离线复核等仅在 FAQ 中说明当前边界，不作为卖点。路线图用于理解产品方向，功能承诺以现有实现与功能清单为准。
