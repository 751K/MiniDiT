# MiniDiT 网页视觉参考

查看日期：2026-11-08。已实际浏览首页与功能段落；以下为设计观察，不将参考网站的功能或商业承诺沿用到 MiniDiT。

- [Things](https://culturedcode.com/things/)：以产品截图为主体，标题、正文和留白保持稳定层级。适合参考整体节奏和原生软件气质。
- [CleanShot X](https://cleanshot.com/)：功能段落围绕一个操作展开，文案与较大的界面演示配对。适合参考功能展示方式；动效要解释实际操作。
- [OffShoot](https://hedge.co/products/offshoot)：直接展示来源、传输、目的地与校验。适合参考 DIT 信息表达；不沿用其深色绿色纹理与商业分级。
- [Transmit](https://panic.com/transmit/)：图标、色彩和视频有完整的品牌语言，但方向更活泼，不作为 MiniDiT 的主视觉参考。

## 本轮结论

以 Things 的留白与层级、CleanShot 的真实操作展示为主要方向。两块功能说明优先使用真实产品截图或短操作录屏，而不是另画不属于软件的迷你界面。

无线段落展示连接设备、新素材出现和导入项目；备份段落展示实际副本结果及校验清单。每段聚焦一个用户能确认的结果，图像留出足够阅读尺寸。

避免用循环移动圆点、装饰性传输线、漂浮照片、泛化图标及虚构进度来填充空白。默认静态；必要动效只用来解释一次具体操作。

两段功能介绍使用原生 SwiftUI 组件导出的静态截图，替换上一版网页交互演示的截图。设备栏、筛选、素材网格和备份标记直接来自当前应用源码，未用 HTML 重画。图片没有交互或动画。

截图为在独立进程中展示的演示状态，不表示真实相机连接或生产素材的实际备份记录。沿用演示中的 Unsplash 照片，来源见 PHOTO-CREDITS.md。辅助进程使用 AppModel(startServices: false)，不启动相机连接、不修改已安装应用的设置。
