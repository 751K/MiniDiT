# MiniDiT 视觉规范

全软件只用一套视觉。新写或修改界面时按这里来；代码里的对应常量在 `Views/Theme.swift`。

## 颜色

| 用途 | 颜色 |
|---|---|
| 可操作、选中（主按钮、开关、选中的缩略图、链接） | 主题蓝（AccentColor，和图标同色） |
| 需要处理的异常（计划中的备份盘不可用、网络权限不足、连接失败、插件需更新） | 橙色，只配警告图标或警告文字 |
| 删除等不可撤销的操作 | 红色，只用在按钮文字上 |
| 正常状态（已连接、已校验、已安装） | 不上色，用正文或灰色说明文字 |

- 不用绿色表示“正常”。正常就是不需要提示。
- 来源页以设备名称、状态和连接操作为主，使用紧凑的设备行；图标为辅助。离线只在设备内说明，不重复全局提示。无可用设备时搜索为主操作，发现设备后搜索降为次操作。连接帮助和手动 IP 输入从底部按需展开；权限或连接异常才使用警告。
- 不用彩色圆点表示状态。需要提示时用一句文字，警告前加橙色的感叹号三角。
- 缩略图状态使用明确文字：一份副本为“✓ 已导入”，两份可访问副本为“✓✓ 已备份”，三份以上显示实际副本数量；导入记录存在但文件不可访问为“不可访问”。橙色单勾表示只有一份，不表示导入失败。

## 底色和分组

- 窗口和面板一律白底（深色模式下跟随系统）。
- 侧栏是系统的灰色底。侧栏里的分组（设备面板、筛选卡片）用浅色半透明底（`Theme.sidebarGroup`），不用白底、不加边框，免得灰底里突然冒出一块白。
- 设置窗口用系统的分组表单（`Form` + `.grouped`）。
- 设置窗口以外需要分组时，用白底 + 细灰边框的圆角面板（`Panel`），圆角 10。
- 不用浅灰填充的块来做分组或强调。

## 字号

字号按信息层级使用，避免 Native List 的默认小号 Section 标题：

| 级别 | 用途 | 字号 |
|---|---|---|
| 标题 | 页面标题（向导每一步、选择来源） | 22 pt 粗体 |
| 区块标题 | 项目、设备、筛选、日期 | 15 pt 半粗 |
| 列表正文 | 日期、星期、项目及主要名称 | 15 pt（媒体子项可为 12 pt） |
| 控件正文 | 选项、按钮、菜单、搜索 | 13 pt |
| 辅助信息 | 路径、状态、条件、数量 | 11–12 pt |

## 控件

| 要做的事 | 用什么 |
|---|---|
| 打开 / 关闭一项 | 系统开关（`Toggle`，`.switch`） |
| 几个里选一个，选项少且短（≤ 3 个） | 分段（`SegmentPicker`）：灰色底槽 + 会滑动的蓝色滑块（蓝底白字，不加玻璃） |
| 几个里选一个，选项多或长 | 系统弹出菜单（`Picker`，默认菜单样式） |
| 几个里选一个，每项对应导入目标 | 线条符号 + 名称 + 开关的一组行，互斥 |
| 几个可以同时选（如文件类型） | 多选分段（`MultiSegmentPicker`），打开的格子是蓝色 |
| 搜索 | 灰色控件槽 + 放大镜；有关键词时显示清除按钮 |
| 搜索旁的筛选 | 标签图标 + 当前条件摘要 + 下拉菜单，不另放独立标题 |
| 不常用的操作 | “…”菜单 |

分段统一用 `SegmentPicker` / `MultiSegmentPicker`（选中是实心蓝色滑块，窗口在后台时也保持蓝色），不再另画其他分段、对勾行、胶囊开关。

### 浮层用玻璃

浮在内容上面的部分（浏览页底部的导入栏、相机断开的提示条、大图预览的底栏）用 macOS 26 的系统玻璃：

- 容器：玻璃胶囊（`glassCapsule()`）。
- 主按钮：蓝色玻璃（`glassButton(prominent: true)`，即 `.glassProminent`）。
- 其他按钮、“…”菜单：普通玻璃（`glassButton()`，即 `.glass`）。
- 开关（“备份”“仅代理”）：`GlassToggle`，打开时蓝色玻璃，关着时普通玻璃。

窗口里的普通界面（顶栏、侧栏、设置、弹窗）不用玻璃，用标准系统控件，分段用 `SegmentPicker`。macOS 26 以前的系统自动退回 bordered / borderedProminent。

## 浏览三栏

浏览页固定为三栏，职责不能混用：

1. **项目**：一级导航和普通导入的必选目标。允许未选项目时浏览设备素材；启动时不自动选中最近项目，移除当前项目后也不自动改选其他项目。
2. **设备与筛选**：设备、当前设备的卡槽、显示范围、导入内容、照片格式、搜索、标记和日期。
3. **素材内容**：当前日期或项目内容的缩略图、数量和底部导入栏。

- 所有已打开设备都参与导入；点击设备行只切换当前正在设置卡槽和查看统计的设备，不关闭或排除其他设备。
- 项目实际同时包含照片和视频时，在项目下显示“照片”“视频”分类；只有一种媒体时不增加层级。
- 项目区和日期列表使用自定义紧凑行，不使用 Native List。项目名称与标题左对齐；媒体子项保留文字缩进，选中背景右边界与父项目一致。
- 日期属于筛选，不单独放在筛选卡片外。选中日期即切换内容范围，并默认选中该日期的新素材。
- 双卡“合并”表示合并两张卡并去重；内容不同则保留全部素材，内容相同则照片和视频都只出现、导入一次。

## 项目选择与新建窗口

- 普通导入必须归入用户选择或新建的项目。未选项目时，底栏主按钮为“新建项目”，摘要提示“请先选择或新建项目”；选中已有项目后，主按钮为“导入”。不以异常颜色表示尚未选项目。
- 从底栏新建时，确认按钮为“新建并导入”；从侧栏主动新建时为“新建”。取消不会创建项目、保存目录修改或开始传输。确认后仍需检查备份、剩余空间和所选后期软件。
- 窗口标题为“新建项目”。上部为“日期”“事件”和最近事件；事件可留空；下部为“保存位置”，分别列出照片、视频目录。只导一种媒体时只显示对应目录。
- “日期”“事件”“照片”“视频”标签使用同一列宽和对齐线；输入框与目录控件的左右边界一致。窗口宽 460 pt，内边距 24 pt，两部分用分隔线和留白分组。
- 保存位置标题、媒体标签和路径均使用正文大小（`Theme.Font.body`）。目录整行使用系统按钮，点击后选择根目录，按当前整理规则实时预览最终路径。主目录可缩写为 `~`；长路径省略中段，悬停显示完整路径。
- 最近事件最多展示两个完整名称，其余放入“更多”菜单。空间不足时减少直接展示项，全部名称过长时使用“选择最近事件”菜单，不把事件按钮压成省略号。
- 不重复显示项目名、文件夹装饰图标或“照片和视频使用各自的整理规则”等泛化说明；仅在名称冲突、选中已有同名项目或日期目录预览需要解释时显示必要提示。
- 自动导入同样要求已选项目；无目标时停止并提示用户。续传使用原任务记录的项目，不随侧栏后来选中的项目改变。

## 导入目标图标

C1 / LrC 的黑白标志直接由本机安装软件的原始素材加工：Capture One 使用其 Resources/appicon_1024.png，Lightroom Classic 使用其 Resources/App.icns 导出的 PNG。去掉底色，从原图保留 C + 内圈、不带外框的 LrC 原始字形，不手画或用系统符号替代。生成脚本为 Scripts/build-software-logo-assets.swift，结果保存在 Assets.xcassets 的两个 Monochrome 图像集中；使用模板颜色，浅色界面黑色、深色界面白色。“仅存储至文件夹”使用黑白的系统文件夹线稿，图形宽度与软件标志对齐；其他位置的文件夹符号保持原有主题色。照片设置的“导入至”列表只显示名称和系统开关，不显示文件夹或第三方标志；“连接”页同样不显示软件图标，保留名称、版本、状态及操作按钮。向导继续使用原标志，顶部标签栏保持原样。

## 按钮

- 主按钮：`.borderedProminent`（主题蓝）。每个画面最多一个。
- 次按钮：`.bordered`。
- 链接式：`.link`，只用在列表行末尾的“更改”。
- 形状交给系统，不设 `buttonBorderShape`。
- 浮层上的按钮用玻璃样式，见上面“浮层用玻璃”。
- 尺寸：一般 `.regular`；页面主操作（连接、向导的继续、弹窗的确认）`.large`；浏览页底部导入栏统一 `.extraLarge`（约 36 pt 高，主按钮文字加粗）。

## 缩略图选择与拖动

- 从已选中的缩略图开始普通左键拖动：拖出全部所选素材，拖动时保留多选。
- 从空白处或未选中的缩略图开始拖动：框选；按住 ⌘ / ⇧ 时在已有选择上增减。
- 单击、⌘ 加选、⇧ 连选、双击预览和右键菜单保持原有行为。
- 拖到桌面或访达文件夹时无需选择项目，只复制原文件，卡上的原片保留；不执行备份，也不写入项目导入记录。
- 拖到左侧任意项目时执行正常导入流程：备份、校验、项目记录和后期软件交接；项目行显示蓝色落点边框。

## 图标

- SF Symbols 线条样式。可操作或代表一类设置时用主题蓝，装饰性的用灰色。
- 第三方软件（Capture One、Lightroom、Resolve、FCP…）用它们自己的图标，读 `.icns` 原图（见 `AppIcon`）。
- 不给图标加彩色底块。

## 文案

- 书面语，简短；标题不用问句。
- 说明文字只写“不知道就会用错 / 用不了”的信息（前置条件、路径）。能从标题看懂的不另写说明。
- 引号用“”。

## MiniDiT 品牌

首页仅使用 MiniDiT 字标，不展示图标，副标题为“导入 · 校验 · 交接”。品牌只出现一次，设备行仍是主要操作区域。品牌字标使用 26 pt 半粗，作为业务字号层级之外的固定标识。应用图标沿用原有 Icon Composer 图层，平面版位于 Apps/MiniDiT/design。

## 多目标备份

- 「设置 › 备份」与向导使用同一目标列表，保持设置顶部标签栏样式。设置页将总开关与位置列表分组，不显示文件夹或磁盘装饰图标。总开关、各目标开关和整理方式开关统一使用 `BackupSettingsSwitch` 的原生 mini 尺寸（与设置表单默认开关一致），右边缘对齐。各目标的开关与名称位于同一行；操作菜单放在名称旁，不占据开关右侧位置。路径使用灰色可点击控件，主目录缩写为 `~`，长路径省略中段；同盘或不可用提示完整显示并用强调色突出，不使用“同盘”等缩写。添加位置使用轻量文字按钮。
- 同一路径及互相包含的目录不能重复添加；同一物理盘提示“与导入位置位于同一块硬盘”或“与其他备份位置位于同一块硬盘”；确认底层硬盘均不重叠时不显示说明。无法查清物理盘时显示“无法确认是否与其他位置共用硬盘”；查询期间不显示临时未确认提示。
- 导入栏显示每个目标的已校验数、总数及当前复制/失败状态；工作文件保存与各目标备份结果分开，单个目标失败不宣告整个导入未保存。
- 项目结果按目标展示历史已校验数量、目录和当前连接状态。每个目标独立提供“核对并补齐”“更换位置”；新增位置只影响该批任务。核验时间属于历史事实，不能因当前离线而清除。
- 目标规则在开始导入时冻结，修改设置只影响后续任务。退出或取消不撤销已保存副本；必需目标未完成时保留原卡文件。

DaVinci Resolve 的外部脚本设置要求不作为开关下方的常驻小字。设置和向导共用 `ResolveImportToggle`，仅在用户将开关从关闭改为开启时弹出说明；关闭开关、重新进入页面和载入已启用的偏好不重复弹窗。

“创意外观”放在「设置 › 照片」中，包含套用 Look 的开关、Capture One 和 Lightroom 的已安装配置列表及 RAW 适用范围。“连接”页只负责软件安装、连接状态、授权及插件管理，不放照片处理偏好。

设置末页命名为“连接”，保留各软件的已安装/未安装、运行与授权状态，以及插件操作。只设“照片后期”和“视频后期”两组：前者包含 Capture One、Lightroom Classic、Adobe Bridge 与 DxO PhotoLab，后者包含 DaVinci Resolve 与 Final Cut Pro。导入目标选择仍在照片和视频页。

通用页的“项目”设置优先显示人可读的命名方式（日期 + 事件、完整日期 + 事件、仅日期、自定义），并展示生成名称示例。常用方式不显示模板语法；只有选择自定义时才显示模板输入框与可用标记说明入口。原有自定义规则自动识别为自定义并保留，不主动重置用户偏好；修改仅影响新建项目。
