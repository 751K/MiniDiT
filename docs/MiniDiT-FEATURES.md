# MiniDiT 功能清单与实测记录

2026-11-09 当前开发版本：MiniDiT 自身的素材归属统一称“项目”，Capture One 专有名词“会话”保留。普通导入必须先选择或新建项目，直接拖到桌面或访达文件夹仍无需项目。浏览界面使用“项目 / 设备与筛选 / 素材内容”三栏；照片、视频及向导的设置顺序统一，推荐设置需主动应用。下表中历史“会话”指现在的项目（注明 Capture One 的除外）；历史实测结果不自动代表修改后的真实相机或后期软件完整流程已经验收。

每项功能的实现要点和实测情况。面向开发者；使用说明见 [README](../README.md)。

**实机**：A7 V（ILCE-7M5）连家里的 Wi-Fi，开着访问身份验证（SSH）。没有实机条件的部分用模拟相机（`swift run fake-sony-camera`）或做的测试卡测。
